综述

  1. Xi, Z., Chen, W., Guo, X., et al. (2023). The Rise and Potential of Large Language Model Based Agents: A Survey. https://arxiv.org/abs/2309.07864
    核心价值：系统梳理 agent 架构、规划、记忆、工具使用、环境交互。
    对你有用之处：帮你把“安全问题出现在哪些模块”定位清楚。
  2. Wang, L., Ma, C., Feng, X., et al. (2023/2024). A Survey on Large Language Model based Autonomous Agents. https://arxiv.org/abs/2308.11432
    核心价值：从 autonomous agents 视角讨论规划、记忆、行动、反馈。
    对你有用之处：适合作为论文开题里“agent 系统结构”背景综述。
  3. 关于 Trustworthy / Secure LLM Agents 的综述性工作（2024–2025）
    这一类通常覆盖：
  • 安全性 safety
  • 可靠性 reliability
  • 对齐 alignment
  • 隐私 privacy
  • 鲁棒性 robustness
  • 可解释与审计 accountability
    对 AgentShield 很重要，因为你需要把系统定位放在 trustworthy agents 而不是只做一个“出口过滤器”。

到 2025 年，agent 安全最前沿很多成果还没完全沉淀成“统一顶刊经典论文集”，而是呈现出：
基础 agent 在 AI 顶会，攻击/防护在安全社区与 arXiv 快速迭代，真正的系统化防护框架正在形成中

攻击面结构

1、Yao, S., Zhao, J., Yu, D., et al. (2023). ReAct: Synergizing Reasoning and Acting in Language Models. ICLR 2023. https://arxiv.org/abs/2210.03629
核心价值：提出“思考—行动—观察”闭环，是现代 agent 范式基础。
AgentShield 的审计对象本质上就是 ReAct 式轨迹：thought / action / observation / state transition。

2、Schick, T., Dwivedi-Yu, J., Dessi, R., et al. (2023). Toolformer: Language Models Can Teach Themselves to Use Tools. NeurIPS 2023. https://arxiv.org/abs/2302.04761
核心价值：把“调用外部工具”正式引入 LLM 系统设计。
一旦工具可调用，安全边界就从“文本生成”扩展为“外部能力编排”。

3、Park, J. S., O’Brien, J., Cai, C. J., et al. (2023). Generative Agents: Interactive Simulacra of Human Behavior. UIST 2023. https://arxiv.org/abs/2304.03442
核心价值：强调记忆流、反思、长期行为。
对你有用之处：为“记忆污染”“长期状态溯源”“行为因果链审计”提供了系统对象。

4、Wang, G., Xie, S., Yu, Z., et al. (2024). Voyager: An Open-Ended Embodied Agent with Large Language Models. https://arxiv.org/abs/2305.16291
核心价值：展示 agent 在长程任务中如何依赖技能库、记忆与环境反馈。
说明为什么单轮安全过滤不够，必须做长期轨迹与技能调用审计。

直接安全层

Greshake, K., Abdelnabi, S., Mishra, S., et al. (2023). Not What You’ve Signed Up For: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection. https://arxiv.org/abs/2302.12173
这是 agent 安全里必须读的经典。
定义了间接提示注入。
对 AgentShield 的意义：你的“隐私出口管控”本质上就是针对这类攻击的最后一道系统级防线。

Perez, F., & Ribeiro, I. (2022). Ignore Previous Prompt: Attack Techniques For Language Models. https://arxiv.org/abs/2211.09527
核心价值：较早系统化了 prompt injection / prompt overriding 的攻击思路。
对你有用之处：虽然更偏模型提示攻击，但它奠定了“指令优先级冲突”问题，这正是 agent 越权执行的源头之一。

Zhan, H., et al. (2024). AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents. [arXiv]
这篇工作很值得重点跟进。
核心价值：开始把 agent prompt injection 从“案例展示”推进到“标准化评测环境”。
对你有用之处：你如果要做 AgentShield，最后一定要有 benchmark；AgentDojo 这类工作能帮你设计评测维度：攻击成功率、越权率、数据泄露率、防护后任务保真度。
说明：我无法实时核验其最终发表 venue，但这条线在 2024–2025 很关键，建议优先补查最终版本。

Ruan, Y., et al. (2024). ToolEmu: Identifying the Risks of LM Agents with an LM-Emulated Sandbox. [arXiv]
核心价值：用模拟环境系统评估 agent 在工具使用中的风险。
对你有用之处：非常贴近你的系统思路，因为它不是只看文本输出，而是看 行动风险、工具副作用、越权调用。
说明：建议你后续核对作者和最终发表信息。

系统防护层

Inan, H., et al. (2023/2024). CaMeL: Defending Against Indirect Prompt Injection Attacks in LLMs by Escaping User Control and Employing Least-Privilege Access Control. [arXiv]
核心价值：把“最小权限”明确引入对抗 indirect prompt injection 的防护设计。
对你有用之处：你的“隐私出口管控”可以直接借鉴这条思想：
不是只判断“回复是否危险”，而是判断“当前上下文是否有权访问/导出该数据”。

相关信息流控制 / least-privilege agent framework 系列工作（2024–2025）
这条研究线不一定都在单篇“爆款论文”里，而是分散在 agent security、secure systems、policy enforcement、sandboxing 相关论文中。
你要重点寻找的关键词是：
information flow control for LLM agents / capability-based security for agents / policy-enforced tool use / action guards / provenance-aware agents。
