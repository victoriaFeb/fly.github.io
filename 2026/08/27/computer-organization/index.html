一.数据表示

1.基础

bit：计算机中最基本的信息单位

byte：计算机存储中最小的可寻址单元

word：机器字长；影响：

  1. CPU一次处理的数据长度
  2. 寄存器宽度
  3. 地址空间

Nibble（半字节）

2.数制系统

2.1 进制转换

（1）整数转换

法1.逐次递减

法2.除留余数

（2）小数转换

乘进制取整数部分，从上往下

2.2 有符号整数表示

原码、反码、补码

原码：最高位表示符号，0-正；1-负

反码：负数符号位不变，其余位取反

（上2都存在两个0）

补码：正数-原码；负数-取反加一

使用补码：加减统一（只需加法器）；0唯一；电路简单

2.3 浮点数表示

科学计数法，三部分组成：符号+指数+尾数

单精度float：32b，1+8+23

双精度double：64b，1+11+52

12345=1.2345 x 10^4

符号 尾数 指数

  • 1.2345 4

偏置指数：存负数时加偏移量

规定有效第一位必须为1，存储时只存小数部分

Q：浮点数为何有误差

eg. 0.1=（0.0001100110011…）计算机存储位数有限，截断产生误差

指数位决定范围，尾数位决定精读

浮点数溢出

  • 上溢：超过

2.4 字符编码

ASCLL：7b，英文字符

Unicode：统一编码

2.5 检错与纠错

（1）校验和checksum

（2）CRC循环冗余校验：模2（XOR）运算

（3）汉明码：纠错

​ 汉明距离：两个码字不同bit数量

最小汉明距离：code中所有对（此处类排列组合）码的最小汉明距离。越大证明检测和纠错能力越高

三.计算机模型

1.CPU基础

CPU:=数据通路（ALU、寄存器、连接总线）+控制单元

数据的存储、传输和运算+根据当前指令和CPU状态产生控制信号

  • 寄存器位于 CPU 内部，用于保存当前计算过程中需要快速访问的数据和控制信息。
  • ALU 负责算术和逻辑运算
  • 控制单元决定执行
  • Bus：一组信号线，每条线同时传输一个 bit。CPU 通过总线与其他系统部件共享/交换数据。

Bus 的两种常见连接方式：

  • P2P
  • 多点：仲裁机制

如果多个设备都有成为 Bus Master 的能力，就可能同时请求使用总线。

去

  1. 集中式仲裁：每个设备直接连接仲裁电路，由集中式仲裁者选择获得总线的设备
  2. 菊花链仲裁：权限按照优先级
  3. 基于冲突检测的分布式仲裁：设备可尝试使用，数据发生冲突则重新尝试
  4. 基于自选择的分布式仲裁：设备之间自行决定

Bus 类别：

  • 地址总线 访问位置
  • 数据总线 传输实际数据
  • 控制总线 传递读写、访问时机和数据传输方向等控制信息

时钟：同步各组件的活动

每次数据移动或运算操作需要一定数量的时钟周期

  • 频率（MHz/GHz）
  • 周期

CPU性能

程序的指令数，运行每条指令所需周期数，每个周期所需的时间

2. I/O子系统

I/O设备通过不同接口连接CPU

（1）存储器映射： I/O 设备像内存一样被访问

（2）基于指令的I/O：CPU 有专门的I/O指令集

3.存储器组成

RAM 芯片写法：l x w

l 个存储位置，每个位置 w bit

存储单元数量 x 每个存储单元的位数

交叉存储

（物理内存常常由多个 RAM 芯片构成）将连续地址交叉分布到不同芯片，可以提高访问效率。

  • 低位：低位bits 决定选择哪个 chip，连续地址往往分布在不同 modules
